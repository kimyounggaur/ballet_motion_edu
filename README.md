# ballet_motion_edu

발레 기본기 3D 모션 교육 웹앱 (Three.js r128, 단일 HTML).

- `ballet3d.html` — 현재 빌드(5단계 후보: 오른 발목 튐 제거, **아직 게시 전**)
- `releases/ballet3d_v6_published.html` — 게시된 v6
- `src/` — 소스(core.js 솔버, figure.js, tutu.js, app.js, style.css, body.html), `build.py`로 조립
- `tests/` — 수치·회귀·영상 스크립트, `docs/ballet3d-spec.md` — 구현 메모
